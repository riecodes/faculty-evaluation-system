## Design Decisions
1. [x] Criteria Type Immutability
   - Type can only be set during criteria creation
   - Type field is hidden during edit operations
   - Backend prevents type changes during updates
   - Rationale:
     * Maintains data consistency
     * Prevents issues with existing questions
     * Avoids confusion in evaluation format
     * Preserves historical data integrity

2. [x] Question Type Inheritance
   - Questions inherit type from parent criteria
   - Type field is hidden in question form
   - Type is automatically set based on selected criteria
   - Rationale:
     * Maintains parent-child relationship
     * Ensures data consistency
     * Simplifies user interface
     * Prevents type mismatches
     * Aligns with criteria type immutability

3. [x] Evaluation Form Type Handling
   - Questions display differently based on type:
     * Checklist: Shows 5-1 rating radio buttons
     * Textfield: Shows textarea for comments
   - Backend stores responses differently:
     * Checklist: Stores rating in 'rate' field
     * Textfield: Stores comment in 'comment' field, rate=0
   - Rationale:
     * Maintains consistent user experience
     * Preserves data structure
     * Allows for different response types
     * Supports both quantitative and qualitative feedback

## Database Integrity
1. [x] Added Cascade Delete Constraints:
   ```sql
   -- Clean up orphaned questions
   DELETE FROM question_list 
   WHERE criteria_id NOT IN (SELECT id FROM criteria_list);

   -- Add foreign key constraints with cascade delete
   ALTER TABLE question_list
   ADD CONSTRAINT fk_question_criteria
   FOREIGN KEY (criteria_id) 
   REFERENCES criteria_list(id)
   ON DELETE CASCADE;

   ALTER TABLE evaluation_answers
   ADD CONSTRAINT fk_answer_question
   FOREIGN KEY (question_id) 
   REFERENCES question_list(id)
   ON DELETE CASCADE;
   ```
   - Ensures data integrity when deleting criteria
   - Automatically deletes related questions
   - Automatically deletes related evaluation answers
   - Prevents orphaned records
